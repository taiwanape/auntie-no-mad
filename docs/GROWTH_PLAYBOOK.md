# 阿姨別生氣推廣與營運手冊

這份文件是給「阿姨別生氣」每天營運用的。目標不是亂灑連結，而是讓網站每天都有可分享、可搜尋、可回訪的內容。

## 核心定位

- 一句話：把台灣生活新聞、踩坑提醒、股票 ETF 觀察，用阿姨碎念講成人話。
- 受眾：一般民眾、婆婆媽媽、學生、剛開始看股市和生活資訊的人。
- 語氣：白話、有梗、犀利但不惡毒，有來源，不亂講。
- 內容主軸：生活雷達、踩坑日記、股市 ETF、工具箱、好物推薦、冰箱便條紙。

## 每日營運節奏

每天早上 7 點前：

- 確認 GitHub Actions 的 Daily Auntie Update 是否成功。
- 確認首頁有更新生活雷達、踩坑日記、股市 ETF、冰箱便條紙。
- 查看 `data/review-report.json`，確認沒有來源缺失、圖片不相干或股市投資建議問題。
- 抽查首頁手機版，尤其是大標、卡片、圖文不要溢出。

每天白天：

- X 發一篇短文：一句生活痛點、一句阿姨碎念、一張圖、一個網站連結。
- Facebook 發一篇較完整的貼文：用故事開頭，引導點進文章。
- Instagram 發圖文或限動：圖要先抓眼球，連結放個人檔案或限動連結。
- 社群貼文不要像公告，要像「阿姨剛看到一件事，忍不住提醒你」。

每天晚上：

- 看來訪數、社群互動、哪篇被點最多。
- 把有反應的題材做成第二天的延伸文章。
- 若內容或圖片不理想，隔天優先修正，不要硬推。

## 每週營運節奏

- 從舊文章挑 2 篇重發，標題換成新的生活角度。
- 補 1 個工具箱小工具，例如單位換算、折扣換算、荷包試算。
- 檢查 Search Console 有沒有新關鍵字、索引錯誤、熱門頁面。
- 檢查社群預覽圖是否正常，FB/LINE/X 分享時標題和圖片不能壞。
- 整理一篇「本週阿姨碎念懶人包」，把 3 到 5 篇內容串起來。

## 平台打法

### X

- 文字短、節奏快、要有一句可轉貼的梗。
- 適合：即時新聞、生活吐槽、股市白話提醒。
- 範例結構：
  - 今天看到一件事
  - 阿姨白話翻譯
  - 圖文重點
  - 連結

### Facebook

- 適合較完整故事，開頭要有情境。
- 可以用「你是不是也遇過」開場，讓人留言分享經驗。
- 每篇貼文都要放網站連結，不要只放圖片。

### Instagram

- 圖比文重要，第一張要像海報。
- 適合生活雷達、踩坑提醒、工具箱。
- 可以用限動做投票，例如「你今天衣服乾了嗎？」

## SEO 基礎

網站已具備：

- `sitemap.xml`：給搜尋引擎抓頁面。
- `robots.txt`：告訴搜尋引擎可抓取範圍。
- `rss.xml`：給 RSS 訂閱器與未來自動分發使用。
- `feed.json`：給程式化讀取、日後自動發文或 APP 使用。
- OG meta：讓 FB、LINE、X 分享時有標題、摘要、圖片。

後續要做：

- 到 Google Search Console 提交 `sitemap.xml`。
- 到 Google Analytics 加入網站流量追蹤。
- 每篇文章標題要像真人會搜尋的問題，不要只有口號。
- 每篇內容都要有來源連結，避免被視為低品質內容。

官方參考：

- Google SEO Starter Guide：https://developers.google.com/search/docs/fundamentals/seo-starter-guide
- Google Sitemaps：https://developers.google.com/search/docs/crawling-indexing/sitemaps/overview
- Google Search Console：https://developers.google.com/search/docs/monitor-debug/search-console-start
- Google Analytics：https://support.google.com/analytics/answer/9304153
- X Create Post API：https://docs.x.com/x-api/posts/create-post

## 內容品質規則

- 圖和內文必須同一件事，不可用舊圖亂套。
- 生活雷達要是真實事件，有來源，有時間，有阿姨白話翻譯。
- 踩坑日記要講「哪裡會踩坑」，不要只寫恐嚇式提醒。
- 股市 ETF 只能寫觀察，不可寫買進、賣出、目標價、保證獲利。
- 圖文要有一個記憶點：笑點、怒點、痛點、或一句金句。

## 成長指標

每天看：

- 首頁來訪數
- 單篇文章點擊
- 社群貼文點擊
- 分享次數
- 手機版跳出率

每週看：

- Google Search Console 曝光與點擊
- 哪些關鍵字帶人進來
- 哪些文章可以改標題再推一次
- 哪些社群平台轉換最好

## 30 天成長計畫

第 1 週：

- 穩定每日更新。
- 每天至少 1 篇社群圖文。
- 補齊 Search Console 與 Analytics。

第 2 週：

- 做 3 個工具箱小工具。
- 生活雷達和踩坑日記各挑一篇做長尾 SEO 文章。
- 開始整理舊文章入口。

第 3 週：

- 建立每週懶人包。
- 開始測試不同社群標題。
- 把最高點擊的文章改成系列內容。

第 4 週：

- 檢查資料，留下有效題材。
- 淘汰沒人點的固定欄位。
- 準備自訂網域與品牌頁優化。

## 不要做的事

- 不要大量到別人社群留言洗版。
- 不要用無來源的假新聞。
- 不要把股市內容寫成報明牌。
- 不要每天只換標題、圖片不換。
- 不要為了流量做太誇張的恐嚇標題。
